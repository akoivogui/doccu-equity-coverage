# Data availability

No individual-level E-SIS data are included in this repository.

The study uses routinely collected cervical screening data held within the regional E-SIS information system of the CRCDC Île-de-France. These data contain sensitive health information and cannot be publicly released.

The public repository contains code describing the analytical definitions and the production of tables and figures. Derived `.rds` cache files used by the production script are intentionally excluded.

Researchers wishing to reproduce the analysis on authorised data should recreate the expected intermediate objects using their approved data environment and configure the environment variables documented in the main README.
