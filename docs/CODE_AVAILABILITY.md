# Code availability statement

The analytical code used to generate the main tables, supplementary analyses, figures and cartographic outputs is publicly available at https://github.com/akoivogui/doccu-equity-coverage and permanently archived as version v1.0.0 in Zenodo (https://doi.org/10.5281/zenodo.24529601). Individual-level E-SIS data are not publicly available because they contain sensitive health information and are subject to applicable data-protection and governance requirements. The public repository therefore provides the analytical definitions and production code but does not contain patient-level data or derived individual-level caches.
